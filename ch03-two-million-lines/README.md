## The scenario

You need the ten most requested pages from a two-million-line log, and your first working version takes long enough that you assume it has hung. It has not. It is just doing far more work than it needs to.

## What you will learn

Measuring your own code with `clock_gettime` before any theory arrives. Linear search, binary search, selection sort, insertion sort, merge sort. Recursion and how it uses the stack. `struct` for grouping related data. The standard library's `qsort`.

Big-O notation shows up only after you have measured the difference yourself, as a name for something you already understand.
